## Publish on GitHub Pages

1. Create a GitHub repository.
2. Upload all files from this ZIP to the repository.
3. Keep the `docs` folder exactly as provided.
4. Open **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Select your main branch and `/docs`.
7. Save and wait for GitHub Pages to publish.

Your Privacy Policy URL will normally be:

`https://YOUR-GITHUB-USERNAME.github.io/YOUR-REPOSITORY/privacy.html`

Included:
- `docs/index.html`
- `docs/privacy.html`
- `docs/terms.html`
- `docs/style.css`
- `docs/.nojekyll`

Important:
The Privacy Policy matches the current offline-first DISHLY build. Update it before release if the app later adds Firebase, accounts, cloud sync, analytics, crash reporting, ads, restaurant APIs, delivery services, reservations, payments, image uploads, location permissions, or any other online/sensitive-data feature.
